## 📌 Project Overview
An open-source simulation engine designed to evaluate route feasibility and energy efficiency by combining geographic pathfinding with terrain elevation data.

## 🚀 Current Status (MVP - Phase 1)
- [x] Initial straight-line trajectory mapping between nodes.
- [x] Topographic altitude extraction and elevation profiling.
- [x] Interactive visual mapping (HTML output)
      link for the visual map: https://augustoferrer.github.io/geo-graph-optimizer/mapa_completo.html

## 🗺️ Roadmap & Vision (Where this project is going)
- [ ] Implement graph-based pathfinding algorithms (Dijkstra / A*) taking elevation gradient constraints into account.
- [ ] Calculate energy/fuel consumption models based on terrain slope.
- [ ] Expand dataset to cover complex public transit and regional railway networks.
